94 characters, one line, no newline.

## How it works

`main.py` validates the line against the competition gate (UTF-8, 1–200
characters, not only whitespace, a single line), writes it to
`/output/entry.txt`, then reads the file back to verify it matches the
entry byte for byte.

Run it with:

```sh
python3 main.py
```
